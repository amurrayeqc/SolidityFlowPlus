# SolidityFlowPlus

SolidityFlowPlus enables High-Performance, Distributed real-time Processing through Auto-Scaling capabilities on a scalable Engine Platform.

With SolidityFlowPlus, you get a lightweight tool that stays out of your way.

## Installation

1. Clone the repository: `git clone https://github.com/harutosati/SolidityFlowPlus.git`
2. Install required dependencies: `pip install -r requirements.txt`

## Configuration

SolidityFlowPlus is configured through environment variables (see `.env.example`). Key options:
- **APP_ENV**: `development` or `production`.
- **PORT**: Port the server listens on.
- **LOG_LEVEL**: `debug`, `info`, or `error`.
